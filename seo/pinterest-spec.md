# Pinterest Pin Graphics Specification

This specification outlines the design rules for generating standard Zuga Fitness Pinterest Pins.

## Dimensions and Format
* **Aspect Ratio**: 2:3
* **Resolution**: 1000px width x 1500px height
* **Format**: High-quality PNG or JPG

## Typography & Copy
* **Headline**: Bold, high-contrast, using the 'Lora' font. **Max 6 words** for immediate readability.
* **Subhead**: Clear, readable sans-serif font (e.g., system UI fonts or standard sans-serif). Used to add context or a secondary hook.
* **Text Overlay**: Must be highly visible. Use gradient overlays or semi-transparent backgrounds behind the text to ensure it pops against the background image.

## Visual Design
* **Background Image**: High-quality, contextually relevant yoga or dance image from the committed asset library (`assets/images/`). The image must match the topic of the pin (e.g., seated stretches for desk worker pins, restorative poses for postpartum, movement for zumba).
* **Brand Logo**: The Zuga logo (`assets/images/zuga-logo.webp`) must be placed in the **bottom-right** corner of every pin.
* **Colors**: Incorporate Zuga brand colors (e.g., the primary coral/orange and dark accents) where applicable, especially in text highlights, badges, or subtle overlays.

## Linking Rule
* **CRITICAL**: Every pin MUST link to a specific, highly relevant page (like a blog post or service page). **Never link a pin to the homepage.**
